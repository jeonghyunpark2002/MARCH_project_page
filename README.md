# MARCH Project Page

Project page for "MARCH: Evaluating the Intersection of Ambiguity Interpretation and Multi-hop Inference" (ACL 2026).

## 🚀 Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "init: MARCH project page"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/march_project_page.git
git push -u origin main
```

Then on GitHub: **Settings → Pages → Branch: main → Save**

Your page will be live at: `https://YOUR_USERNAME.github.io/march_project_page/`
